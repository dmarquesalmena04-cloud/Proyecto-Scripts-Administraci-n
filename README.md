#  Portfolio Scripts - Administrador de Sistemas y Redes

Repositorio con scripts funcionales y útiles para tareas de administración de sistemas y redes.  
Nivel: ASIR 1 | Lenguajes: Python, Bash (en progreso) | Plataforma: Windows / Linux

---

##  Objetivo
Demostrar conocimientos prácticos de automatización de tareas del administrador de sistemas:
- Monitoreo de recursos del equipo.
- Copias de seguridad automáticas.
- Escaneo básico de red local.
- Scripts listos para usar en entornos reales.
